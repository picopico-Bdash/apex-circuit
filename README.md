# Apex Circuit

ブラウザで遊べる 3D サーキットレースゲームです（three.js r128）。
CPU 4台との周回レース。コース3種（グランプリ / テクニカル / 峠）、天候3種（晴れ / 雨 / 夕暮れ）、難易度と周回数を選べます。

**▶ プレイ: https://picopico-Bdash.github.io/apex-circuit/**

## 操作

| キー | 操作 |
|---|---|
| ↑ / W | アクセル |
| ↓ / S | ブレーキ・バック |
| ← → / A D | ハンドル |
| Space | サイドブレーキ（ドリフト） |
| C / R / Esc | 視点切替 / コースに戻る / ポーズ |

スマートフォンでは画面左下のハンドルと右下のアクセル・ブレーキで操作します。

## 画質（GPU なしでも遊べる軽量モード）

タイトル画面の「画質」で **自動 / 高画質 / 軽量** を選べます（設定はブラウザに保存されます）。
「自動」は、ブラウザのハードウェアアクセラレーションが使えない環境（SwiftShader などのソフトウェア描画）を検出すると軽量モードになります。
URL に `?quality=low` / `?quality=high` を付けて切り替えることもできます。

軽量モードでは次のように描画負荷を下げます（操作感・物理・CPU の強さは変わりません）。

- 内部解像度を下げて拡大表示し、フレーム時間に合わせて自動調整（動的解像度）
- 影をオフにして車の下に簡易影を表示、アンチエイリアスなし
- 材質を軽いライティング（Lambert）に置き換え、凹凸マップと異方性フィルタリングを省略
- 霧を手前に寄せ、コース脇の木・タイヤバリア・フェンスは約 360 m 以内だけ描画、木の本数を削減
- 20 m より遠い CPU カーは簡易ボディで描画、煙・雨の粒子を削減、描画は最大 30 fps

GPU を無効にした Chrome（ソフトウェア描画）での計測では、高画質 約 0.5 fps → 軽量 約 22〜26 fps でした。

## 構成

```
docs/                GitHub Pages で公開されるサイト（ビルド結果）
  index.html         ページ本体（HUD・メニュー・CSS）
  js/game.js         ゲーム本体
  models/*.glb       車体・コース小物の glTF モデル
game.html            ゲームコードのソース
src/shell.html       ページの HTML/CSS テンプレート
build_docs.py        game.html + src/shell.html から docs/ を生成
```

ゲームを修正したら `game.html` を編集して `python build_docs.py` を実行し、`docs/` をコミットしてください。

ローカルで試す場合は、`fetch()` でモデルを読み込むため HTTP サーバー経由で開いてください:

```bash
python -m http.server 8000 --directory docs
```
